ภารกิจหลังจบคดี
ส่งคำตอบ 1 ชิ้นเป็นข้อความหรือไฟล์ เพื่อสร้างแบบจำลองความจริงของคดีจากหลักฐาน และออกแบบเทคโนโลยีหรือระบบที่มีเหตุผลรองรับว่าอาจช่วยให้เหยื่อรอดได้

รูปแบบที่ส่งได้
- ข้อความในระบบ
- เอกสาร .txt, .docx หรือ .pdf
- สไลด์หรือภาพประกอบที่มีคำอธิบายครบตามหัวข้อ

มาตรฐานคำตอบ
คำตอบต้องเป็นแบบจำลองเชิงสาเหตุ ไม่ใช่เพียงการเล่าเรื่องหรือเดาตัวผู้กระทำ คุณต้องเชื่อมหลักฐานทางกายภาพ ดิจิทัล ชีวภาพ การเงิน หรือไทม์ไลน์เข้าด้วยกันตามที่คดีมีให้ และระบุความไม่แน่นอนอย่างตรงไปตรงมา

สิ่งที่ต้องส่ง

1. แบบจำลองความจริงของคดี
- อธิบายว่าเกิดอะไรขึ้นกับเหยื่อ และกลไกหรือห่วงโซ่เหตุการณ์ใดนำไปสู่ความเสี่ยงหรือการเสียชีวิต
- สร้างไทม์ไลน์อย่างน้อย 3 จุด: ก่อนเกิดเหตุ / จุดเปลี่ยนสำคัญ / ผลที่ตามมา
- ใช้วัตถุพยานอย่างน้อย 3 ชิ้น จากอย่างน้อย 2 ประเภทของหลักฐาน
- ระบุสำหรับหลักฐานแต่ละชิ้นว่า บอกอะไร, ไม่สามารถบอกอะไรได้, และทำให้สมมติฐานใดเข้มแข็งขึ้นหรืออ่อนลง
- เสนอสมมติฐานทางเลือกอย่างน้อย 1 ข้อ แล้วอธิบายว่าหลักฐานใดสนับสนุนหรือหักล้างมัน
- แยกข้อมูลเป็น 3 ระดับ: ข้อเท็จจริงที่ยืนยันได้ / ข้อสรุปที่อนุมานได้ / สิ่งที่ยังไม่ทราบ

2. เทคโนโลยีเพื่อให้เหยื่อรอด
- ตั้งชื่อระบบหรือแนวคิดของคุณ
- ระบุผู้ที่ได้รับความช่วยเหลือ ช่วงเวลาที่ต้องแทรกแซง และความเสี่ยงเฉพาะที่ระบบต้องลด
- อธิบายกลไก: ระบบรับข้อมูลอะไร ตรวจพบสัญญาณใด ตัดสินใจอย่างไร และทำอะไรต่อเมื่อพบความเสี่ยง
- ออกแบบการป้องกันเป็นชั้นอย่างน้อย 2 ชั้น เช่น การป้องกันก่อนเกิดเหตุ การตรวจจับ การเตือน การช่วยเหลือ หรือการส่งต่อมนุษย์
- อธิบายเหตุผลว่าทำไมเทคโนโลยีนี้จึงตอบ failure mode ที่หลักฐานในคดีชี้ให้เห็น
- ระบุอย่างน้อย 2 ข้อจำกัดหรือ failure mode ของระบบ รวมถึงปัจจัยมนุษย์ เช่น คนเพิกเฉยต่อการเตือน ใช้งานผิด หรือเชื่อข้อมูลระบบมากเกินไป
- ระบุข้อมูลส่วนบุคคล ความยินยอม หรือความเสี่ยงด้านความเป็นธรรมที่ต้องจัดการ หากแนวคิดของคุณใช้ข้อมูลของบุคคล

3. ผลต่อคดี
- ระบุจุดในไทม์ไลน์ที่เทคโนโลยีของคุณจะเข้าแทรกแซง
- อธิบายผลลัพธ์ที่คาดว่าจะเปลี่ยนไป โดยไม่อ้างว่าเทคโนโลยีแก้ปัญหาได้แน่นอนเกินหลักฐาน
- บอกว่าหลักฐานชิ้นใดทำให้คุณเชื่อว่าการแทรกแซงนั้นมีโอกาสช่วยเหยื่อได้

เกณฑ์การประเมิน 20 คะแนน
- แบบจำลองเชิงสาเหตุและไทม์ไลน์: 4 คะแนน
- การใช้หลักฐานหลายประเภทและการเชื่อมโยงของหลักฐาน: 4 คะแนน
- การแยกสิ่งที่ยืนยันได้ อนุมานได้ และยังไม่ทราบ: 3 คะแนน
- เทคโนโลยีที่เฉพาะเจาะจงและสอดคล้องกับ failure mode ของคดี: 4 คะแนน
- การออกแบบการป้องกันเป็นชั้น ข้อจำกัด และปัจจัยมนุษย์: 3 คะแนน
- ความชัดเจนของเหตุผลและความเชื่อมโยงระหว่างเทคโนโลยีกับโอกาสรอด: 2 คะแนน
