# CreativeLabTH Group Fonts

These files are copied from the current CreativeLabTH Group web project.

## Font roles

| Family | Files | Role |
| --- | --- | --- |
| `LINESeedSans` | `LINESeedSans_W_*.woff2` | Latin UI, navigation, labels, and body copy |
| `LINESeedSansTH` | `LINESeedSansTH_W_*.woff2` | Thai UI and body copy |
| `FCSubject` | `FC Subject [Non-commercial use] *.otf` or `*.ttf` | Display headings, dates, and short brand statements |

The weight mapping used by the token stylesheet is:

| Suffix | CSS weight |
| --- | ---: |
| `Th` | `100` |
| `Rg` | `400` |
| `Bd` | `700` |
| `He` | `800` |
| `XBd` | `900` |

The UI normally needs regular and bold. The other weights are included for future editorial and campaign work.

## Licensing and redistribution

Preserve this file with the font files when the kit is copied. The FC Subject filenames explicitly identify a non-commercial-use font. Confirm the font creator's current license before using it in commercial deliverables or redistributing it outside the CreativeLabTH Group team.

Do not convert, rename, subset, or publish the font files as a separate font product without permission from the respective rights holders.
